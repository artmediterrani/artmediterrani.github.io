# ART MEDITERRANI — borrador

Copia de trabajo para GitHub Pages: https://artmediterrani.github.io/

Las páginas HTML, CSS, JavaScript y assets están en la raíz. Las traducciones están en es/ y en/. No requiere instalación ni compilación.

Cada página incluye noindex para mantener este borrador fuera de los resultados de búsqueda. Conserva la URL canónica de la web principal.

## Publicación

1. Revisar los cambios y hacer commit en la rama de trabajo.
2. Publicar la rama en artmediterrani/artmediterrani.github.io.
3. Crear una PR hacia main y revisar antes de fusionar.
4. En Settings > Pages > Build and deployment, seleccionar Deploy from a branch, main y / (root).
5. Al actualizar main, GitHub Pages publica esta copia. Revisar el resultado en Actions.

Dejar vacío Custom domain para conservar la dirección de GitHub Pages.
