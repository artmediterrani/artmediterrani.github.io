Static GitHub Pages website. French at root, Spanish in `/es/`, English in `/en/`. Five pages per language. No build step or external fonts, tracking or runtime services.

## Contact form
The form validates fields and prepares a message for WhatsApp or the visitor’s email application. It does not send requests, store records or offer a delivery guarantee. Visitors must confirm sending in their chosen app. Email links require an email handler. The copy button provides an alternative.

## Assets and content
The primary logo is the supplied “Logo mediterrani amb paella i mar.png”, preserved without alteration and without an enclosing circle. The local QR encodes https://wa.me/34697305143. No invented photography, prices, customer claims or fixed guest minimums. The gallery includes four supplied photographs credited to Roberto Lorente Brigido and five selected paella photographs credited to their photographers. Optimized local images and responsive variants live in assets; gallery-credits.json records original filenames and source references. Prices remain on request until actual indicative amounts are supplied.

## Upload
Back up the existing repository, then upload the CONTENTS of this folder to its root. Keep `assets`, `es` and `en` directories. GitHub Pages can serve the root of the selected branch. Preserve any existing domain configuration. Review changes before merging. Do not upload `.git` or the outer ZIP folder.

## Preview
Serve this directory with any static HTTP server. Open index.html. The site also supports direct file navigation; automatic clipboard copying may require HTTPS or localhost.
